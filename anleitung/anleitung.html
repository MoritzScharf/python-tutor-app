Python-Tutor

Anleitung: herunterladen, installieren, loslegen · Stand Version 2.10.1

Hier lädst du das Programm herunter (Windows). Ein Klick, der Download startet sofort:

Python-Tutor für Windows herunterladen →

Mac: Apple-Chip (M1, M2 …) · Intel-Mac (Apfel-Menü → „Über diesen Mac“ zeigt, welcher)

1

Herunterladen

Klick auf den Link oben. Dein Browser lädt die Datei sofort herunter (etwa 125 MB). Gibt es eine neuere Version, holt sich das Programm sie selbst.

2

Installieren

Doppelklick auf die heruntergeladene Datei. Du brauchst keine Administratorrechte, die Installation läuft von selbst.

!
Windows warnt dich einmal („Der Computer wurde durch Windows geschützt“). Das ist normal. Klick auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.
i
Auf dem Mac: .dmg öffnen, Python-Tutor in Programme ziehen. Blockiert macOS das Programm beim ersten Start: Meldung schließen, dann Systemeinstellungen → Datenschutz & Sicherheit, ganz unten „Dennoch öffnen“. Das ist nur einmal nötig.
3

Code eingeben

Beim ersten Start fragt das Programm einmal nach deinem persönlichen Zugangscode (so sieht er aus: PYT-XXXXX-XXXXX). Den hast du von der Person bekommen, von der du den Link hast. Tippe ihn ein und klicke auf Freischalten. Dazu braucht das Programm einmal Internet. Jeder Code gilt für ein Gerät.

i
Noch kein Code? Das Programm ist in der Testphase und nur mit Code benutzbar. Schreib der Person, von der du diese Anleitung hast, dann bekommst du einen Code.
4

Loslegen

Nach der Installation startet der Python-Tutor von selbst. Du findest ihn danach im Startmenü bzw. unter Programme, am Symbol mit dem Doktorhut.

  • Links wählst du ein Kapitel und ein Thema. Dort stehen Erklärungen und Beispiele.
  • In jeder Aufgabe schreibst du Code, klickst auf Ausführen und dann auf Prüfen. Die Tests zeigen dir, was noch fehlt.
  • Mit Schritt für Schritt siehst du, wie dein Programm Zeile für Zeile abläuft.
✓
Dein Lernstand bleibt erhalten. Fortschritt und Code liegen im Ordner Dokumente\Python-Tutor-Daten. Bitte nicht löschen. Bei Updates und beim Deinstallieren bleibt er unangetastet.

Lektionen und Aufgaben

8 Kapitel von print bis zu Klassen und 270 Aufgaben aus dem Alltag: Mensa, WG-Kasse, Kino …

Probeklausur

Links unter „Probeklausur“: wie eine echte Klausur, mit Zeit und Auswertung am Ende.

Dein Stand pro ThemaNEU 2.10

Vor jedem Thema zeigt ein Zeichen, wie es steht: noch nicht angefangen, auf dem Weg, wackelt noch oder sitzt. Unter „Üben und wiederholen“ nennt „Dein nächster Schritt“, was jetzt am meisten bringt.

Selbsttest und WiederholenNEU 2.10

Am Ende jeder Lektion 4 Fragen zum Thema, freiwillig. Falsch beantwortete kommen mit den gelösten Aufgaben nach 1, 3, 7 und 14 Tagen zurück (höchstens 5 am Tag), unter „Üben und wiederholen“.

Neue AufgabenartenNEU 2.10

Ablauf protokollieren: Welchen Wert hat jede Variable nach jeder Zeile? Meldung lesen: Zeile, Bedeutung und Behebung eines echten Fehlers. Dazu die Code-Puzzles, in denen du Zeilen ordnest.

Fehler besser verstehenNEU 2.8

Klappt ein Test nicht, sagt ein Satz unter „Erhalten“, was abweicht (zum Beispiel ein Leerzeichen zu viel). Oft derselbe Fehler? Dann zeigt die Karte „Dein häufigster Fehler“ einen Tipp. In der Probeklausur gibt es keine Hilfe.

Zeichnen mit der SchildkröteNEU 2.6

Aufgaben, bei denen dein Code ein Bild malt. Auf der Seite „Frei zeichnen“ probierst du einfach aus.

Erst raten, dann sehenNEU 2.4

Ein Schalter im Schritt für Schritt-Modus: Er fragt dich vorher, welchen Wert eine Variable bekommt oder was ausgegeben wird.

Hilfe von Claude

Optional: mit deinem eigenen Claude-Konto

Claude (die KI von Anthropic) gibt dir Denkanstöße und Zusatzaufgaben. Das Programm benutzt dafür dein eigenes Konto. Ein Gratis-Konto reicht (es gelten die Gratis-Limits von Claude).

Einfach: Die Knöpfe „Frag Claude“ und „Erklär mir den Fehler“ öffnen Claude mit einer fertigen Frage. Nur noch Enter drücken. Klappt das Öffnen nicht, kopiert das Programm die Frage: mit Strg+V einfügen.

Noch bequemer: Erweiterung für Claude Desktop

Dann sieht Claude selbst, an welcher Aufgabe du sitzt, und kann dir Zusatzaufgaben anlegen. Einmal einrichten (braucht Claude Desktop):

1
Claude Desktop öffnen → Einstellungen → Erweiterungen.
2
Auf „Erweiterung installieren…“ klicken (manchmal unter „Erweiterte Einstellungen“) und die Datei python-tutor.mcpb wählen. Du findest sie im Programm: links auf „Claude verbinden“, dann der Knopf „Datei im Ordner zeigen“. Du kannst sie auch direkt ins Fenster ziehen.
3
Claude Desktop neu starten, im Programm auf „Verbindung prüfen“ klicken. Dort steht dann „Verbunden“.
i
Beim Öffnen von Claude steht oben eine Warnung. Sie ist normal. Steht dort „Cowork“, wähle „Chat“.
✓
Geht die Erweiterung bei dir nicht, ist das kein Problem: Die Knöpfe funktionieren auch so. Eine Zusatzaufgabe holst du dir dann über Claude und fügst sie unter „Extra von Claude“ mit „Aufgabe aus Zwischenablage einfügen“ ein.

Wenn etwas nicht klappt

  • Windows blockiert die Installation: „Weitere Informationen“ → „Trotzdem ausführen“ (siehe Seite 1).
  • „Noch nicht verbunden“ bei „Claude verbinden“: Erweiterung installiert und Claude Desktop ganz neu gestartet? Dann nochmal „Verbindung prüfen“.
  • Claude Desktop ist nicht installiert: Die Knöpfe öffnen dann claude.ai im Browser. Das geht auch.
  • Etwas anderes: Schick Moritz ein Foto von der Meldung.
