Python-Tutor

Installationsanleitung · Stand: Version 2.6.0 (November 2026)

Der Python-Tutor ist ein Programm zum Python-Lernen, ganz ohne Vorwissen. Du bekommst Lektionen zu allen Grundthemen (von print bis zu Klassen), viele Aufgaben aus dem Alltag (Mensa, WG-Kasse, Kino …), einen Schritt-für-Schritt-Debugger und eine Probeklausur. Python musst du nicht extra installieren, das bringt das Programm mit.

Nach jedem Update zeigt dir das Programm kurz, was neu ist.

1. Herunterladen

  1. Öffne github.com/MoritzScharf/python-tutor-app/releases
  2. Nimm ganz oben die neueste Version und klick unter „Assets“ auf
    Windows: Python-Tutor-Setup-2.6.0.exe (die Nummer kann bei einer neueren Version höher sein)

Mac: Für den Mac gibt es gerade keine Datei zum Herunterladen. Sobald es eine gibt, steht bei der Version eine .dmg-Datei (arm64 für Macs mit Apple-Chip M1/M2/M3 …, x64 für Intel-Macs). Die Mac-Anleitung steht unten schon bereit.

2. Installieren

Das Programm ist (noch) nicht bei Microsoft oder Apple „signiert“. Deshalb warnt dein Rechner beim ersten Start einmal. Das ist normal, das Programm ist in Ordnung.

Windows

  1. Doppelklick auf die heruntergeladene .exe-Datei. Du brauchst keine Administratorrechte.
  2. Erscheint „Der Computer wurde durch Windows geschützt“: Klick auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“.
  3. Die Installation läuft von selbst. Danach findest du Python-Tutor im Startmenü und auf dem Desktop.

Mac (sobald verfügbar)

  1. Doppelklick auf die .dmg-Datei und zieh Python-Tutor in den Ordner „Programme“.
  2. Doppelklick auf Python-Tutor in „Programme“. Der Mac meldet, dass er das Programm nicht prüfen konnte. Klick auf „Fertig“ (oder „OK“).
  3. Öffne Systemeinstellungen → Datenschutz & Sicherheit, scroll ganz nach unten und klick bei der Meldung zum Python-Tutor auf „Dennoch öffnen“. Passwort oder Touch ID eingeben und mit „Öffnen“ bestätigen. Das musst du nur beim ersten Start tun.
  4. Auf macOS 14 und älter geht auch: Rechtsklick auf das Programm → „Öffnen“ → noch einmal „Öffnen“.

3. Erster Start

  • Nutzungsdaten: Das Programm fragt dich einmal, ob es anonyme Nutzungsdaten senden darf. Das ist freiwillig. Es werden nie dein Code, deine Eingaben, dein Name oder deine IP-Adresse gesendet. Du kannst es jederzeit unter „Datenschutz und Statistik“ abschalten.
  • Alter Lernstand aus VS Code? Das Programm sucht beim ersten Start kurz nach der alten VS-Code-Fassung. Findet es sie, fragt es oben „Übernehmen?“. Sonst klick links auf „Lernstand aus Ordner übernehmen …“ und wähl den alten Ordner Python-Tutor. Im alten Ordner ändert sich dabei nichts.

4. Deine Daten

Dein Fortschritt und dein Code liegen in Dokumente/Python-Tutor-Daten (darin meine-daten). Der Ordner bleibt bei Updates und beim Deinstallieren erhalten: nicht löschen! Willst du an einem anderen Rechner weitermachen, nimm den Ordner mit.

Unter „Einstellungen“ gibt es „App zurücksetzen“, falls du ganz von vorne anfangen willst. Vorher fragt das Programm noch einmal nach und legt automatisch eine Sicherung an.

5. Neue Version

  • Windows: Das Programm lädt neue Versionen selbst. Oben erscheint ein Hinweis. Klick auf „Jetzt neu starten“, dann wird die neue Version sofort installiert und das Programm startet neu. Oder du wartest einfach bis zum nächsten Start.
  • Mac: Oben steht ein Hinweis mit „Herunterladen“. Neue .dmg laden und das Programm wieder in „Programme“ ziehen (alte Version ersetzen).

Dein Lernstand bleibt dabei immer erhalten.

6. Claude als Lernhilfe (freiwillig)

Die Knöpfe „Frag Claude“ und „Erklär mir den Fehler“ öffnen Claude mit einer fertigen Frage. Du musst sie nur noch mit Enter abschicken. Dafür brauchst du ein eigenes Claude-Konto (ein Gratis-Konto reicht). Ist Claude Desktop installiert, öffnet sich das, sonst claude.ai im Browser. Klappt das nicht, ist die Frage kopiert: in Claude mit Strg+V (Mac: Cmd+V) einfügen und Enter drücken.

Erweiterung für Claude Desktop

Damit sieht Claude, an welcher Aufgabe du sitzt, und kann dir Zusatzaufgaben anlegen. Klick im Programm links auf „Claude verbinden“ und folge den Schritten:

  1. Claude Desktop öffnen → Einstellungen → Erweiterungen.
  2. „Erweiterung installieren…“ (manchmal unter „Erweiterte Einstellungen“) und die Datei python-tutor.mcpb wählen oder ins Fenster ziehen. Wo sie liegt, zeigt dir im Programm der Knopf „Datei im Ordner zeigen“.
  3. Claude Desktop neu starten, dann im Programm auf „Verbindung prüfen“ klicken. Dort steht danach „Verbunden“.

Oben in Claude steht dann eine Warnung, die ist normal. Steht dort „Cowork“, wähl „Chat“. Geht die Erweiterung nicht, funktionieren die Knöpfe trotzdem. Zusatzaufgaben fügst du dann unter „Extra von Claude“ mit „Aufgabe aus Zwischenablage einfügen“ ein.

7. Wenn etwas nicht klappt

  • Windows oder macOS warnt beim Start: Siehe Schritt 2. Beim ersten Start ist das normal.
  • Die Frage kommt nicht in Claude an: Sie ist kopiert. Mit Strg+V (Mac: Cmd+V) einfügen und Enter drücken.
  • „Noch nicht verbunden“: Claude Desktop nach dem Installieren der Erweiterung ganz neu starten, dann noch einmal „Verbindung prüfen“.
  • „Claude Desktop ist auf diesem Rechner nicht zu finden“: Claude Desktop installieren oder die Knöpfe mit dem Browser nutzen.
  • Fehlermeldung oder anderes Problem: Sag der Person Bescheid, von der du den Link hast, am besten mit einem Foto der Meldung.
